to enable use of github actions do the following:

1- go to settings page -> actions -> general -> workflow permissions - enable "read and write permissions"

2- in the pages section -> build and deployment -> set source to "github actions"

3- push update to repo using git

---

this is a full file viewer for the repo that rebuilds on every push.

live at: https://junguler.github.io/placeholder/

what it does:

- browse the whole repo (or any local folder on your machine) right in the browser
- grid view + list view + sidebar tree
- search, breadcrumbs, pin folders, favorite files
- preview almost everything: code, text, markdown, images, audio, video, playlists (m3u/m3u8 etc)
- open zip / tar / tgz archives and browse inside them (including nested archives)
- download any folder as a zip
- local folder mode — pick a folder from your device (nothing gets uploaded, stays completely offline)
- media player with playlist support + a bunch of recording options
- image gallery rail when you're looking at pictures

themes & looks:
- light / dark / auto / high-contrast dark / high-contrast light / concrete / vivid
- custom accent color + intensity slider
- corner radius from completely square to fully rounded
- font size, density, zebra striping, player button style (icons / labels / both), etc
